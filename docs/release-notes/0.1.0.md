RJID 0.1.0 is the first public preview of RJID (Rust for Java IDE): a Java IDE written in Rust on GPUI, with project-aware Run/Debug, Java language intelligence, a real terminal, and a debugger.

- Project detection for plain Java, Maven, Gradle, Spring Boot (web-aware), JavaFX and Android.
- New Project wizard: Java console, Spring Boot web, JavaFX × Maven / Gradle / no build tool.
- Completion with auto-import, hover docs, quick fixes, rename and refactorings via the Eclipse JDT Language Server.
- Generate constructor, getters/setters, toString and equals/hashCode from the right-click menu.
- Debugger: breakpoints, step over/into/out, variables and call stack.
- VT terminal; Spring Boot's "started on port" becomes a one-click localhost link.
- Opt-in, IntelliJ-style update checks for the JDK, Maven, Spring Boot and JavaFX.
- Movable panels, drag-and-drop folders, 5 themes, portable settings.

Windows is the tested platform; macOS and Linux are experimental.

Build from source: see the README ("Get RJID"). No binaries are published.
